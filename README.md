# ReviewMovie

Sistema que permite buscar películas o series, registrar la calificación, escribir una reseña y consultar el historial de cuantas películas o series ha reseñado cada usuario.

## Problema que resuelve

La indecisión si esa película es buena o mala, así como que sensaciones y/o perspectivas causo a cada usuario.

## Reglas de Negocio

* El usuario podrá buscar películas o series por su titulo 
* La calificación es obligatoria, la reseña opcional.
* Solo se puede crear una reseña por película o serie, el usuario puede editar la calificación de una película o serie ya reseñada.
